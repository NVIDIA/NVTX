◆ domain

nvtxDomainHandle_t nvtxwStreamAttributes_t::domain

Domain used implicitly for all events and counters written into this stream.

NULL means the session default domain. Schemas, enums, scopes, counters, strings, and resources used by data written to this stream must be registered in this domain. Multiple streams may share a domain; all of them see the entities registered in it.

◆ scopeId

uint64_t nvtxwStreamAttributes_t::scopeId

Default scope for events and counters written into this stream.

A per-event scope or process/thread payload entry overrides it. Other values than NVTX_SCOPE_NONE or NVTX_SCOPE_ROOT must be registered in this stream's domain. Runtime-resolved scopes (NVTX_SCOPE_CURRENT_*) are invalid here.

◆ timeDomainId

uint64_t nvtxwStreamAttributes_t::timeDomainId

Default time domain for event and counter timestamps written into this stream.

A per-event or per-counter time domain overrides it. A non-zero value must be a predefined NVTX_TIMESTAMP_TYPE_* value or a time domain ID registered in this stream's domain.
