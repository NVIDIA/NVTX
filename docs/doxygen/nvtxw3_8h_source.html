68/* A backend library exposes a single exported entry point, `nvtxwGetInterface`,
69 * which maps an interface version to a function table. The optional reference
70 * loader in nvtxw3_loader.h (`nvtxwLoad`) locates the backend and resolves this
71 * symbol; an application may instead load a backend by any mechanism it prefers,
72 * resolve the "nvtxwGetInterface" symbol itself, and request the desired
73 * nvtxwInterface_* function table.
74 *
75 * Configuration: NVTXW does not define a mechanism for load-time or
76 * backend-global configuration. A backend may define its own mechanism, such as
77 * a backend-specific environment variable. Per-session options are passed
78 * through `nvtxwSessionAttributes_t::configString`. */
79
