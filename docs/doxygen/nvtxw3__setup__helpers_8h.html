Open a stream and produce a ready-to-use event writer in one call.

Convenience for the common case of one stream per domain: registers all event helper schemas in domain, opens a stream on it (see nvtxwStreamOpen for the scopePath and timeDomainId arguments), and fills writerOut with the interface, the opened stream, and the (by-value) schema IDs. The resulting writer is passed directly to the event write functions.

For several streams sharing one domain, prefer registering the schemas once (nvtxwEventSchemasRegister) and building each writer with nvtxwEventWriterInit, to avoid registering the schemas once per stream.

const nvtxwInterface_t **  interfaceOut,
nvtxwModuleHandle_t *  moduleOut 
)

Load and initialize an NVTXW backend and return the core interface table.

library is passed directly to nvtxwLoad – NULL uses the default search (overridable by the NVTXW3_LIBRARY environment variable), or a backend filename/path loads that library specifically. If moduleOut is non-NULL, it receives the implementation-defined module handle that keeps the backend loaded. The caller must keep that module handle alive while using the returned interface. If moduleOut is NULL, the backend remains loaded until process exit.

Open a stream in a session.

domain (from nvtxwDomainRegister, or NULL for the session default domain) is the stream's implicit domain for all events and counters written to it. scopePath, when not NULL, is registered as the stream's default scope. timeDomainId sets the stream's default time domain (NVTX_TIME_DOMAIN_ID_NONE if none), overridden by per-timestamp semantics.
