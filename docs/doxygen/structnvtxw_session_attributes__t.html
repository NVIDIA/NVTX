const char* nvtxwSessionAttributes_t::configString

String containing configuration options for the session.

Format is key=value entries separated by any of \r (carriage return), \n (line feed), or | (pipe); a delimiter must not appear in a key or value. The first = (equals sign) separates the key from the value, so a key must not contain =. Tools shall use reasonable defaults for supported options the caller omits, and ignore keys they do not support. See tool-specific documentation for lists of supported keys.
